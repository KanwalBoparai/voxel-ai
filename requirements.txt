# Runtime dependencies — installed into the Vercel serverless function.
#
# Vercel caps an unzipped function bundle at 250 MB, so this list is kept to
# what the app actually imports. Local-development-only packages (the uvicorn
# server, the SQLite driver) live in requirements-dev.txt and are deliberately
# NOT installed in production.
#
# Removed and why — do not add these back without checking the size budget:
#   pandas / numpy   ~104 MB, was used only to parse an upload CSV; the stdlib
#                    `csv` module does the same job (see app/api/campaigns.py).
#   elevenlabs       app/services/voice.py calls the REST API with httpx; the
#                    SDK was never imported.
#   apscheduler      needs a long-lived process, which serverless has no way to
#                    provide. Nothing imported app/services/scheduler.py.
#   psycopg2-binary  asyncpg is the driver actually in use.
#   alembic          never imported; schema is created by scripts/init_db.py.
#   google-api-      ~76 MB, almost entirely 522 bundled API discovery docs. We
#     python-client  used exactly three Calendar endpoints, so
#                    app/services/google_calendar.py now calls the REST API
#                    directly with httpx + a google-auth bearer token.
